# Plataforma de Inscripción Institucional

Una aplicación web dinámica diseñada para agilizar el proceso de inscripción de nuevos ingresantes y, al mismo tiempo, proporcionar a los administradores herramientas eficientes para la gestión, control y procesamiento de datos.

## 🚀 Características
- **Inscripción de Alumnos:** Formulario interactivo y accesible para el registro inicial de nuevos aspirantes.
- **Panel de Administración:** Interfaz privada para que los administradores puedan visualizar, filtrar y gestionar los registros de los ingresantes de manera centralizada.
- **Validación de Datos:** Control estricto tanto en el cliente como en el servidor para garantizar la integridad y precisión de la información ingresada.
- **Base de Datos Relacional:** Almacenamiento seguro, estructurado y persistente de los datos de la matrícula.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3
- **Backend:** PHP
- **Base de Datos:** SQL (MySQL)
- **Arquitectura:** Modelo Cliente-Servidor con renderizado dinámico de contenido.

## ⚙️ Instalación y Ejecución
1. Cloná este repositorio en el directorio de tu servidor local (por ejemplo, `htdocs` o `www`).
2. Importá el diseño de la base de datos provisto (`database.sql`) en tu servidor MySQL.
3. Ajustá las credenciales de conexión a la base de datos en el archivo de configuración (`config.php`).
4. Abrí tu navegador y navegá a `http://localhost/nombre-del-repositorio` para ejecutar la plataforma.

# Institutional Enrollment Platform

A dynamic web application designed to streamline the registration process for new applicants while providing administrators with tools for efficient data management and control.

## 🚀 Features
- **Student Enrollment:** Interactive and user-friendly form for new applicant registration and document tracking.
- **Admin Dashboard:** Secure interface for administrators to view, filter, and manage applicant records in real-time.
- **Data Validation:** Strict client-side and server-side validation to ensure clean and accurate information entry.
- **Relational Database:** Optimized data structure for secure and persistent applicant data storage.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3
- **Backend:** PHP
- **Database:** SQL (MySQL)
- **Architecture:** Client-Server model with dynamic content rendering.

## ⚙️ Installation and Setup
1. Clone this repository to your local server directory (e.g., `htdocs` or `www`).
2. Import the provided database schema (`database.sql`) into your local MySQL environment.
3. Update the database connection parameters in the configuration file (`config.php`).
4. Open your web browser and navigate to `http://localhost/your-repository-name` to launch the platform.
