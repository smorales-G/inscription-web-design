# Diseño y Funcionamiento para web de inscripción

La finalidad de esta web es no solo se basa en la inscripción de nuevos ingresantes, sinó también en el manejo de datos de los mismos por parte de un administrador.

# Design and Functionality of the Registration Web Platform

The purpose of this platform is not only to handle the enrollment of new applicants, but also to enable administrators to manage and process their data.
